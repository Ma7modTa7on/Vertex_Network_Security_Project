# Brute Force Attack 🔑

## 📌 Description
Brute Force is an attack method where the attacker systematically tries multiple combinations of usernames and passwords until successful access is achieved.

## ⚠️ Impact
- Unauthorized access to systems or accounts.
- Compromise of sensitive data.
- Potential privilege escalation.

## 📷 Screenshot (Before Rules)
![Brute Force Screenshot](../before_rules/brute_force.png)

## 🛡️ Defense (After Rules)
- Enforce strong password policies.
- Implement account lockout after multiple failed attempts.
- Use multi-factor authentication (MFA).
- Monitor logs for suspicious login activity.
